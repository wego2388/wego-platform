# ADR-0004: jOOQ persistence

- Status: Accepted
- Date: 2026-08-08

## Context

Wego needs explicit SQL and transactional behavior with compile-time schema feedback.

## Decision

Use jOOQ as primary persistence. Generate types from the Flyway-owned schema and keep generated records in infrastructure adapters. Do not use Hibernate/JPA as the primary architecture.

## Consequences

Queries remain visible and database features remain available. Schema generation consistency is a build gate. Domain models require explicit mapping.
