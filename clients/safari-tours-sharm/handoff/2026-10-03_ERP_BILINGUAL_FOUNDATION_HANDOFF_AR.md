## ما ستراه

- [x] مبدّل `EN / العربية` في الدخول وفي شريط الداشبورد، قابل للاستخدام
  بالكيبورد، مع تمييز اللغة الحالية.
- [x] اللغة محفوظة في cookie وظيفية لا تحتوي بيانات شخصية؛ تصل إلى SSR
  فيعرض `lang/dir` الصحيحين من أول استجابة، قبل JavaScript.
- [x] التبديل أثناء ملء نموذج الدخول يحافظ على البريد وكلمة المرور؛ الأخطاء
  الظاهرة تتغير لغتها فورًا بدون إرسال طلب دخول جديد.
- [x] التنقل، الدخول، الرئيسية، كشف اليوم، وصفحة الخطأ العامة بالعربي والإنجليزي.
- [x] الحالات ومواعيد اليوم والأعداد والعملات مترجمة/منسقة للعرض. قيمة المال
  الأصلية والعملة لا تتغيران؛ تنسيق المال يحافظ على السنتات بدون float.
- [x] صفحة غير موجودة تظل HTTP 404 مع رسالة مترجمة.
- [x] روابط الحجز في الرئيسية قابلة للكيبورد؛ قوائم الموظف تحافظ على نفس
  حدود الصلاحيات الموجودة.
- [x] الرئيسية توضح أنها تعرض آخر 100 حجز، وليست تقرير إيرادات شاملًا.
- [x] كشف اليوم يعمل على الموبايل، والطباعة تحفظ RTL وتستخدم خلفية ورق بيضاء.
- [x] إصلاح تباين النصوص الثانوية بعد أن كشفه axe؛ لم تُعطَّل قاعدة الاختبار.
- [x] الصفحات الباقية تُعرض كإنجليزية مع تنبيه جاهزية واضح عند اختيار العربية،
  و`lang=en/dir=ltr` للمحتوى فقط؛ شريط التنقل يظل بلغة الموظف.

أسماء الرحلات ووحدات التسعير تظل حقائق الكتالوج الإنجليزية المتاحة في عقد
staff الحالي؛ لم نخترع ترجمة تجارية أو نغير API لنشر اسم غير معتمد.

دليل فحص الأساس السابق؛ مراجعة node-forge لا تمتد إلى braces. التفاصيل
والحدود في `2026-10-03_ERP_BOOKINGS_BILINGUAL_PROGRESS_AR.md`.

  install/validate/OpenAPI/YAML/audit نجحت، ولا توجد ثغرات معروفة في فحصه الحالي.
- [x] E2E dependency audit: لا توجد ثغرات معروفة.
- [x] أداة الاختبارات Vitest وmocker أصبحتا 4.1.11 بتثبيت patch مركزي؛
  أعيد install بالـfrozen lockfile، واختفى التحذيران المتوسطان من audit.
- [!] Web dependency audit: HIGH واحدة في `node-forge@1.4.0` عبر Nuxt CLI /
  listhen، موجودة أيضًا في lockfile قبل تعديلات هذه المرحلة؛ لا نسخة npm
  مصححة منشورة وقت الفحص. audit --prod يُظهرها أيضًا لأن Nuxt هو dependency،
  لذلك لا يكفي القول إنها devDependency.
- [x] فحص التعرض الفعلي والمراجعة المستقلة: listhen يستخدم forge لإنشاء/توقيع

  `.output` كاملة لم يجد node-forge أو listhen. Docker runtime ينسخ `.output`
  فقط، وليس كامل workspace dependencies. أكد `/root/wego016sec_review` هذه
  النتائج بتشغيل الفحوص مستقلًا؛ لا نعتبر هذا إصلاحًا للثغرة أو نجاحًا لـaudit.
