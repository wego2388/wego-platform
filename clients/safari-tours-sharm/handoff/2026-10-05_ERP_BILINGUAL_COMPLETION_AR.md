  المالية، التقييمات، الموظفون، التحكم في البيع، الإعدادات.
- [x] اختيار اللغة محفوظ، RTL/LTR صحيح، وتغيير اللغة لا يمسح الفلاتر
  أو ملاحظات البيع أو كلمات المرور أو اختيارات الأدوار قبل الحفظ.
- [x] Customers أصلحت طلب `size=500` غير المسموح: صفحة واحدة حتى 200 حجز؛
  لا توسعة PII أو صلاحيات. «قيمة الحجوزات في النتائج» بدل «إنفاق العميل»،
  وعرض كل عملة منفصلة بدقة؛ تشمل غير المدفوع/الملغى وتوضح ذلك.
- [x] المالية من سجل الدفع الحقيقي كما كانت: الاعتراف والاسترداد وتاريخ
  القاهرة لم تتغير؛ التعريب يحافظ على السالب والسنتات والعملة الأصلية.
- [x] الرسائل توضح نطاق حتى 200 نتيجة؛ النتائج القديمة لا تستبدل الفلتر
  الأخير، وإعادة إرسال رسالة مرسلة تحتاج تأكيدًا. الفشل الغامض لا يُعرض نجاحًا.
- [x] شاشة الموظفين لا توسع أي صلاحية أو endpoint؛ المدخلات والأوامر كما
  كانت، والـpassword يُمسح عند إغلاق reset. أوصاف الخادم والأكواد تُحفظ أصلية.
- [x] أصلح خروج أزرار الموظفين عن شاشة 360px؛ ليس إخفاء overflow بالمقص.
- [x] التقييمات بلا تقييمات أو شهادات مصطنعة؛ لا فلاتر مظهرية قابلة للتركيز
  وهي aria-hidden. المصادر غير متصلة، ولا تدعي اللوحة عدم وجود تقييمات خارجيًا.
- [x] الإعدادات للعرض فقط؛ API إعدادات الشركة غير منفذ في backend الحالي،
  وحالة 404 واضحة. اختبار fixture بيانات لا يعني أن API صار موجودًا.
- [x] فشل حفظ Sales يطلب التحقق/التحديث بدل ادعاء «لم يتغير شيء»؛ لا retry
