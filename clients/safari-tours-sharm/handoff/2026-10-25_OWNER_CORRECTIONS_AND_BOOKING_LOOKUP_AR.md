## 2. مشكلة «حجزي» المثبتة

طلب الموقع يرجع مرجعًا يبدأ بـ`STQ-`، بينما صفحة «حجزي» كانت تنادي عقدًا يقبل `STR-` فقط ويقرأ الحجوزات وحدها. كان رفض STQ بالتحقق `400` يتحول في الواجهة إلى «تعذّر الاتصال بالخادم»، فتبدو المشكلة انقطاعًا رغم أن نوع المرجع غير مدعوم.

### التغيير المحلي

- [x] توسيع **نفس** مسار `POST /api/v1/tours-operator/bookings/lookup` لقبول STQ مع الحفاظ على STR. لا endpoint جديد غير محمي ولا بحث برقم الهاتف وحده.
- [x] كل بحث يلزم المرجع الكامل **ورقم الهاتف الأصلي**. الطلب غير الموجود والهاتف المخالف يعيدان النتيجة العامة نفسها، دون إظهار اسم أو بريد أو رقم عميل.
- [x] بيانات الطلب في STQ تقتصر على حالته والتاريخ المفضل والعدد والتقدير وقت الطلب؛ لا اسم أو بريد أو فندق أو ملاحظات الطلب. عند تحويله يتضمن الحجز المرتبط بنفس إسقاط STR العام الموجود، بما فيه فندق الاستلام. لا تتحول متابعة الطلب إلى تأكيد أو تحصيل.
- [x] نجاح البحث ونتيجة عدم التطابق تحملان `Cache-Control: no-store`؛ المسار الحالي يحتفظ بمحدد المعدل والرفض من نطاق الموظفين. لا تغيير للصلاحيات أو قواعد الدفع.
- [x] صفحة الأربع لغات تفرق طلبًا جديدًا وقيد المراجعة ومغلقًا ومحوّلًا. بعد التحويل تبقى متابعة STQ ممكنة وتعرض مرجع STR وحالته، بما فيها الإلغاء.
- [x] الأرقام العربية في الهاتف ومرجع STR تتحول إلى أرقام قياسية. رقم الهاتف يحتاج كود الدولة؛ لا تخمين لبلد العميل ولا إتاحة نتائج بهاتف قريب أو آخر أرقامه فقط.
- [x] `400/404/422` تعرض إرشادًا لتصحيح البيانات، و`429` انتظارًا، وأخطاء الشبكة/الخادم تبقى أخطاء اتصال. أزيل إدراج مرجع الاسترداد في رابط واتساب من صفحة النتيجة.
- [x] أضيف رابط «حجزي» بعد نجاح إرسال طلب الموقع؛ الرابط لا يحمل المرجع أو الهاتف في query string.
- [x] **25 أكتوبر / Claude:** E2E معزول على صور الإصدار نفسها: enquiry 44/44، حارس سجل الدفع PASS، طلب الموقع→ERP مع STQ 8/8. (CI للبنية تعطّل بحد بيانات public ECR؛ وظائف الكود خضراء).

- [x] بوابات backend والويب والعقود وFoundry المحلية نجحت، بالأوامر والنتائج النهائية أدناه. قبول E2E الحي وCI والنشر منفصل.
- [ ] E2E حي معزول وتحقق before/after، ثم CI لنفس SHA المرشح عند اعتماد حفظ التغييرات المحددة.
- [ ] نسخة مشفرة حديثة واستعادة معزولة، وفحص V35 الحالي وخطة forward-fix/تعطيل البريد المتوافقة؛ لا رجوع لباك إند قديم فوق V35/36.
