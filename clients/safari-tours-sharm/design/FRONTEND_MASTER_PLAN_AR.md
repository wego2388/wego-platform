## 1. الفكرة في سطرين

موقع يحسّ الزائر إنه **"شاف الرحلة قبل ما يحجزها"**: صفحة كل رحلة بتحكي قصتها
بالخريطة والصور وإنت بتنزل، والانتقال بين الصفحات سلس زي تطبيق، واختيار الرحلة
والحجز والدفع في أقل عدد خطوات — وكل ده يفتح بسرعة على موبايل سائح في فندق.

**معيار كل قرار:** هل ده بيخلّي العميل يفهم أسرع ويحجز أسهل؟ لو لأ، مش هنعمله.

## 2. المبادئ الأربعة (غير قابلة للتفاوض)

1. **سريع:** LCP ≤ 2.5 ثانية على موبايل متوسط، والصفحة تشتغل كاملة من
   السيرفر (SSR) قبل أي JavaScript.
2. **صادق:** لا أسعار أو تقييمات أو "فاضل مكانين" مخترعة. أي معلومة غير
   معتمدة تظهر كناقصة في الـ ERP، ولا تظهر للعميل.
3. **متاح للكل:** WCAG 2.2 AA، والعربي RTL صحيح من أول تحميل، وكل حاجة تشتغل
   بالكيبورد وقارئ الشاشة.
4. **ذكي في الإحساس:** الحركة بتشرح (مش بتزيّن)، وتتوقف تلقائيًا مع
   `prefers-reduced-motion`.

### 3.3 باقي الـtokens

- مسافات: شبكة 4px. حاويات: 1280px (محتوى) / 720px (قراءة).
- Radius: control 10 / card 16 / media 20 / pill.
- ظلال: 3 مستويات فقط (base/raised/overlay) بلون ocean شفاف.
- z-index: base / sticky / dropdown / sheet / modal / toast.
- Motion tokens: `instant 100ms` / `quick 180ms` / `base 260ms` / `reveal 500ms`،
  و easing واحد رئيسي `cubic-bezier(0.22, 1, 0.36, 1)`.

### 3.4 العناصر البصرية المميّزة

- **خط الأفق:** منحنى رفيع (شمس تغرب ↔ موجة) يفصل الأقسام — SVG واحد خفيف.
- **أيقونات:** Lucide عبر `@nuxt/icon` (SVG مضمّن، بدون emoji خالص).
- **رسومات الفئات:** 5 رسومات خطية بسيطة (قارب، جمل/كثبان، معبد، مسرح، باص).
- **Mockups:** كل صورة ولوجو لهم placeholder شيك بنفس المقاس النهائي (gradient
  بلون الفئة + رسمها الخطي + اسم الرحلة)، والمسار ثابت:
  `public/media/tours/<slug>/cover.avif` و`public/brand/logo.svg` — استبدال ملف
  = تحديث الموقع.

## 4. المعمارية التقنية

### 4.1 الإطار والتقديم

- **Nuxt 4 (الموجود) + Vue 3.5** — مفيش تغيير إطار.
- **Route rules (تقديم هجين):**
  - الرئيسية والفئات وقائمة الرحلات وصفحات الرحلات: SSR مع كاش قصير (ISR ~5
    دقائق) — سرعة ثابتة + بيانات حديثة.
  - الأسعار والمواعيد المتاحة: تتجاب لحظيًا من الـAPI دايمًا (مش من الكاش).
  - الحجز والدفع و"حجزي": `ssr` بدون كاش + `noindex`.
- **روابط اللغات (`@nuxtjs/i18n` v10):** `/en/...` `/ar/...` `/ru/...` `/it/...`
  مع `x-default` → `/en`، و`html lang/dir` من السيرفر.
  - اختيار اللغة التلقائي من المتصفح **أول مرة بس**، وبعدها اختيار الزائر يتحفظ.
  - تغيير اللغة يوديك لنفس الصفحة باللغة التانية.

### 4.2 البيانات

- `useFetch`/`$fetch` على السيرفر لأول تحميل (SEO)، و **Pinia Colada** للكاش
  والتحديث على المتصفح (مثلًا تحديث المواعيد لو الزائر ساب الصفحة مفتوحة).
- الأنواع من `@wego/api-contract` (المولّدة من OpenAPI) — مصدر واحد للحقيقة.
- **بحث وفلترة لحظية:** MiniSearch على كتالوج الـ30 رحلة (بيتحمّل مرة، ~10KB).

### 4.3 النماذج والحجز

- **VeeValidate + Zod v4:** نفس قواعد التحقق للعميل والسيرفر.
- **libphonenumber-js:** رقم دولي صحيح (مهم لواتساب والتأكيد) مع اختيار الدولة.
- الحفظ المؤقت لبيانات الحجز غير الحساسة في `sessionStorage` لو الزائر رجع.

### 4.4 التحليلات والخصوصية

- **@nuxt/scripts:** أي أداة تتبّع (GA4/Meta) تتحمّل **بعد موافقة الزائر** فقط،
  وبدون بيانات شخصية أو أرقام حجز في الأحداث.
- شريط موافقة بسيط بالـ4 لغات (قبول/رفض بنفس الوضوح).

### 4.5 PWA

- **@vite-pwa/nuxt:** تثبيت على الموبايل، وصفحة "حجزي" + آخر حجز متشاف تشتغل
  بدون نت (مفيد في الصحرا)، وصفحة offline أنيقة. **مفيش** push notifications.

## 7. صفحات الموقع (كل صفحة بالتفصيل)

الصيغة لكل صفحة: الهدف · الأقسام · المكوّنات · البيانات · الحالات · موبايل ·
الحركة · SEO. كل الروابط تحت `/{locale}`.

### 7.1 الرئيسية `/`
- **الهدف:** في 5 ثواني يعرف "بيعملوا إيه، بكام تقريبًا، وأحجز إزاي".
- **الأقسام:**
  1. Hero: صورة/فيديو صامت + عنوان قصير + `ExploreBar` + زرار "ساعدني أختار".
  2. الفئات الخمس (`CategoryTile`) بعدد الرحلات الحقيقي.
  3. "الأكثر طلبًا" — 6 رحلات (ترتيب يحدده الـERP، مش مخترع).
  4. خريطة سينا (`SinaiMap`) — كل الرحلات على الخريطة، اضغط تفتح الرحلة.
  5. `TripFinder` مدمج.
  6. "ليه تحجز مباشر معانا" — نقاط مثبتة فقط (سعر نهائي بدون مفاجآت، دفع آمن،
     تأكيد فوري، دعم واتساب).
  7. أسئلة شائعة مختصرة + تواصل.
- **الحركة:** Hero يظهر مرة واحدة (fade + رفع خفيف)، الأقسام reveal خفيف بـ CSS.
- **SEO:** Organization + WebSite + ItemList للأكثر طلبًا.

### 7.2 كل الرحلات `/tours`
- **الأقسام:** عنوان + بحث لحظي + `FilterPanel` + شبكة `TourCard` + عدد
  النتائج + ترتيب (الأنسب، السعر، المدة).
- **الحالات:** تحميل (skeleton)، مفيش نتائج (اقتراح إزالة فلتر + واتساب).
- **موبايل:** الفلاتر في Sheet بزرار ثابت "فلترة (3)".
- **الحركة:** الكروت بتترتب بـ layout animation لما الفلتر يتغير.
- **SEO:** canonical بدون query params، ItemList.

### 7.3 الفئة `/tours/{category}` (بحر، صحرا، ثقافة، عروض، انتقالات)
- Hero صغير بلون الفئة ورسمها + وصف قصير معتمد + نفس شبكة الرحلات + أسئلة خاصة
  بالفئة.
- **SEO:** عنوان ووصف لكل فئة × لغة، BreadcrumbList.

### 7.4 صفحة الرحلة `/tours/{category}/{slug}` — أهم صفحة
- **الأقسام:**
  1. Hero: صورة الغلاف (نفس صورة الكارت بـ View Transition) + الاسم + المدة +
     الفئة + "من €X".
  2. ملخص سريع (أيقونات): المدة، الأوقات المتاحة، مناسب للأطفال؟، اللغات،
     الاستلام من الفندق؟ — **يظهر بس لو معتمد**.
  3. `TourStory` — المحطات على الخريطة مع النزول.
  4. `Gallery`.
  5. المشمول / غير المشمول (`IncludesList`).
  6. "اعرف قبل ما تروح" (لبس، مستوى اللياقة، …) — معتمد فقط.
  7. سياسة الإلغاء (`PolicySummary` من السياسة الفعلية للرحلة).
  8. أسئلة الرحلة.
  9. رحلات مشابهة.
- **`BookingCard`:** تقويم الأيام المتاحة → الوقت → العدد → السعر الإجمالي →
  "احجز الآن". على الموبايل شريط ثابت تحت يفتح Sheet.
- **الرحلات REQUEST_ONLY (زي القارب الخاص):** بدل الحجز، نموذج طلب + واتساب.
- **SEO:** `TouristTrip` + `Offer` بالسعر الحقيقي (EUR) + BreadcrumbList +
  FAQPage + صورة مشاركة مولّدة (اسم الرحلة + السعر + اللوجو).

### 7.5 "ساعدني أختار" `/trip-finder`
- 4 أسئلة بخطوات (كارت لكل سؤال، رجوع ممكن) → 3 ترشيحات مع السبب → حجز أو
  مقارنة. النتيجة في الرابط (تتشارك). `noindex`.

### 7.6 الحجز `/book/{slug}` (خطوات)
1. **الموعد والعدد** (لو مش جاي من صفحة الرحلة محدد).
2. **بياناتك:** الاسم، الموبايل الدولي، الإيميل (اختياري لكن مشجّع: "هيوصلك
   التأكيد")، الفندق والغرفة، طلبات خاصة.
3. **المراجعة:** `PriceSummary` + السياسة + موافقة على الشروط → "ادفع €X".
4. التحويل لـ Paymob.
- **الحالات:** الموعد اتملى أثناء الحجز (تحديث المتاح + رسالة واضحة)، ضغط مكرر
  (زرار pending)، خطأ شبكة (البيانات ماتضيعش)، rate limit.
- **الحركة:** انتقال سلس بين الخطوات، مفيش أي حركة تأخر الزرار.
- `noindex`، ومفيش بيانات شخصية في الرابط أو التحليلات.

### 7.7 نتيجة الدفع والتأكيد `/booking/result` → `/booking/confirmation`
- انتظار تأكيد السيرفر (polling محدود) — **مش** بنقول "تم" من مجرد الرجوع.
- التأكيد: `ConfirmationTicket` (رقم الحجز + QR + التفاصيل) + إضافة للتقويم +
  "هيوصلك إيميل" (لو فيه إيميل) + واتساب + حفظ للاستخدام بدون نت (PWA).
- الفشل/الإلغاء: رسالة واضحة + جرّب تاني + واتساب.

### 7.8 حجزي `/my-booking`
- إدخال رقم الحجز + الموبايل (POST، مش في الرابط) → التفاصيل + الحالة + السياسة
  + تواصل. آخر حجز يتحفظ على الجهاز للفتح بدون نت.

### 7.9 صفحات المعلومات

- `/contact` — واتساب أولًا، تليفون، إيميل، ساعات الدعم، خريطة المكتب/نقطة التجمع.
- `/faq` — أسئلة عامة بالفئات + FAQPage schema.
- `/cancellation-policy` — السياسات الثلاث الفعلية (STANDARD/FLEXIBLE/

- `/privacy` · `/terms` — نص يعتمده محمد/محامي.
- `404` / `500` / offline — branded، بلغة الزائر، مع بحث وواتساب.
